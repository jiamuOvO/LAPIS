# FEC 电解液筛选：研究设计草案 v0.1

**状态：待研究人员审查；禁止生成执行请求。** 本文给出可讨论的默认值，不表示已验证的力场、已完成的计算或科研结论。范围依据 [案例草案](fec_screening_draft.json)；原设计文档中的数值和“已完成”状态只作示意。

## 研究问题与候选

- 目标：在 298 K 比较 Li⁺ **自扩散系数** (D_{Li}^{self})，单位 m²/s；另外记录 Li⁺ 第一溶剂化壳层中 EC、DMC、FEC 和 PF₆⁻ 的配位数分布。不把自扩散等同于离子电导率、循环寿命或器件性能。
- 对照：EC/DMC–LiPF₆，不含 FEC。
- 干预：同一基础体系添加 FEC，目标 **1.0 wt%**；建议定义为 `m(FEC) / m(最终电解液，含 LiPF₆) = 0.010`。对照组用同一 EC:DMC 比例补足被 FEC 替代的溶剂质量。
- 暂定基础配方：EC:DMC = **1:1 体积比（加盐与 FEC 前，298 K）**；LiPF₆ = **1.0 mol/L（最终电解液，298 K）**。这些是待审查的比较基准，不是用户给定事实。文献中存在 1:1 体积比、1 M 的 EC/DMC–LiPF₆ 参照体系，但不能据此直接认定本模型有效。参考：[EC/DMC–LiPF₆ 原始研究](https://www.osti.gov/servlets/purl/1238740)。
- 组分计数与 NPT 平衡后体积会影响实际浓度；构型生成须记录目标和实现值，并在生产模拟前核对两组的最终浓度、FEC 质量分数及 EC:DMC 比例。允许偏差需在试运行后预先锁定；若超差，重新构型，不在分析阶段事后筛掉不利结果。

## 计算路线及审批门槛

1. **力场选择尚未确定。** 先列出覆盖 Li⁺、PF₆⁻、EC、DMC、FEC 的完整参数与版本、来源、许可和文件哈希；检查混合规则、电荷模型、长程静电及截断约定。用基线体系的密度、溶剂化结构和 Li⁺ 扩散参照评估适用性，再决定是否用于 FEC 比较。atomate2 有 OpenMM 电解液工作流与自定义力场入口，但工作流可运行不等于力场适用。[atomate2 OpenMM 文档](https://materialsproject.github.io/atomate2/user/codes/openmm.html)。
2. **试运行建议值，不是正式采样承诺：**每个候选先做一个独立种子的 NPT 平衡试运行（起步 5 ns）及生产试运行（起步 20 ns），记录密度、能量、温度、离子位移和 FEC–Li⁺ 接触次数。科研人员根据这些轨迹确定最终体系大小、独立重复数和生产时长；正式比较暂拟 **每候选至少 3 个独立初始构型/随机种子**。若统计不足则延长或停止，不把起步时长当作充分性证明。
3. 原始输入、拓扑、力场文件、种子、平台和软件版本、运行日志、轨迹、盒尺寸、checkpoint 全部保留并计算 SHA-256。预估资源与最长运行时间必须在冻结执行请求前经人工批准。
4. 借助 MDAnalysis 计算 MSD 时需使用跨周期边界的连续坐标；分别分析独立重复，禁止将轨迹首尾直接拼成一条连续轨迹。[MDAnalysis MSD 文档](https://docs.mdanalysis.org/stable/documentation_pages/analysis/msd.html)。

## 预注册的质量检查草案

- **作业结束**：软件退出码、预期文件、帧数、日志与 checkpoint 完整。该状态不代表数值收敛。
- **采样与数值**：温度、压力/体积、密度和能量随时间检查；确认平衡段已剔除；MSD 的拟合区间必须避开早期非扩散段，并做不同拟合窗口、分块及独立重复敏感性分析。拟合区间和可接受变动幅度在正式生产前锁定。少量 FEC 分子导致配位统计不足时，只报告“不足以判断”。
- **物理可靠性**：基线体系与可信参照比较，检查模型覆盖、组分浓度、体系尺寸效应；有限周期盒中的扩散系数可能有系统尺寸偏差，需要尺寸敏感性检查，必要时考虑有适用前提的修正。[Yeh–Hummer 原始研究](https://pubs.acs.org/doi/pdf/10.1021/jp0477147)。
- **证据边界**：只在两组条件可比且质量合格时报告带不确定度的 (D_{Li}^{self}) 差值及溶剂化观察值。即使二者同向变化，也只能称“与某机制相容”，不能声称 FEC 通过该机制改善循环寿命，更不能声称器件性能已验证。
